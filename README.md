# Tolerance Calculator (ISO 286 끼워맞춤 공차 계산기)

**버전: 1.0**

ISO 286-1 / ISO 286-2 규격에 기반한 기계부품 끼워맞춤(fit) 공차를 계산하는 스킬입니다.
`10h6`, `25H7`, `50k6` 같은 **치수 + 공차 기호 + 등급** 형식의 표기를 입력하면,
상한 편차(upper deviation), 하한 편차(lower deviation), 공차 폭(tolerance width)을 mm 단위로 반환합니다.

## 기능

- ISO 286-1 / ISO 286-2 표준 테이블 구현 (치수 범위 **0–500 mm**, IT 등급 **IT1–IT18**)
- 축(shaft) 기호 `a~z`, 구멍(hole) 기호 `A~ZC`, 대칭 기호 `js`/`JS` 지원 (`v`, `x`, `y`, `z` 포함)
- 구멍(K~ZC) 억지/중간 끼움의 **Δ(Delta) 보정**과 **N9 이상 ES=0 예외 규칙** 적용 (ISO 286-2)
- 결정론적(deterministic) 계산 — 수동 계산 오류 없이 표준 테이블 값을 그대로 사용

## 사용법

Python 3로 스크립트를 실행합니다.

```bash
python3 scripts/tolerance_calculator.py "<표기>"
```

여러 표기를 한 번에 처리하려면 함수를 import해 사용합니다.

```bash
python3 -c "import sys; sys.path.insert(0,'scripts'); from tolerance_calculator import get_tolerance; print(get_tolerance('25H7'))"
```

> 참고: 파일을 직접 실행하면(`python3 scripts/tolerance_calculator.py`) 내장된
> 자체 테스트(self-test) 세트가 실행되며 인수는 무시됩니다. 특정 값을 계산하려면
> 위 `-c` import 방식을 사용하세요.

## 출력 형식

함수는 아래 키를 가진 딕셔너리를 반환합니다.

| 키          | 의미                          | 단위 |
|-------------|-------------------------------|------|
| `nominal`   | 명목(기본) 치수               | mm   |
| `class`     | 공차 클래스 (예: `h6`)        | —    |
| `grade`     | IT 등급 (예: `IT6`)           | —    |
| `upper`     | 상한 편차 (es / ES)           | mm   |
| `lower`     | 하한 편차 (ei / EI)           | mm   |
| `tolerance` | 공차 폭 (upper − lower)       | mm   |

편차는 명목 치수 기준의 부호를 가진 오프셋입니다. 실제 최대·최소 치수는
`nominal + upper`와 `nominal + lower`로 구할 수 있습니다.

## 표기 규칙

- **소문자 = 축(shaft)**, **대문자 = 구멍(hole)** — 부호 반전은 스크립트가 자동 처리
- **`h` / `H`**: 편차 중 하나가 0으로 고정 (`h`: 상한 = 0, `H`: 하한 = 0)
- **`js` / `JS`**: 명목 치수 기준으로 대칭 (±IT/2)
- **구멍 Δ 보정 (ISO 286-2)**: 억지/중간 끼움 구멍(대문자 K~ZC)은 상한 편차가 `ES = −ei + Δ`
  로 계산되며, `Δ = IT(n) − IT(n−1)`입니다. 명목치 > 3mm일 때만 적용하며,
  K/M/N은 등급 ≤ 8, P/R/S/T/U/V/X/Y/Z는 등급 ≤ 7까지 적용됩니다.
- **N9 이상 예외**: 구멍 `N`이 등급 ≥ 9(N9~N18)이면 Δ 규칙과 무관하게 `ES = 0`
- **30mm 미만 미지원**: `t`, `v`, `y` 기호는 30mm 미만 크기 구간에서 정의되지 않아
  해당 구간 입력 시 에러가 발생합니다 (잘못된 값 대신 명시적 오류 반환)

## 예시

입력: `25H7`

- 상한 편차: `+0.021 mm`
- 하한 편차: `0.000 mm`
- 공차 폭: `0.021 mm`

→ 구멍 치수 범위는 **25.000 mm ~ 25.021 mm**

## 에러 처리

지원하지 않는 입력에는 `ValueError`가 발생합니다.

| 원인 | 메시지 |
|------|--------|
| 치수가 0–500 mm 범위 밖 | "지원하지 않는 치수 범위" |
| 등급이 IT1–IT18 범위 밖 | "지원하지 않는 IT 등급" |
| 미지원 기호 | "지원하지 않는 공차 기호" |
| `t`/`v`/`y`를 명목치 ≤ 30mm로 사용 | "이 치수 범위(30mm 미만)에서 정의되지 않습니다" |
| 형식 오류 (`<숫자><기호><등급>` 아님) | "형식을 인식할 수 없습니다" |

에러 발생 시 지원되는 범위/형식을 안내하고 수정된 표기를 요청하세요. 추측으로 계산하지 않습니다.

## 적용 범위

- ✅ ISO 286 끼워맞춤 공차 계산 (상한/하한 편차, 공차 폭, 허용 치수 범위)
- ❌ 일반 단위 변환, GD&T 기호 해석(기본 편차 제외), 비-ISO 규격은 대상 아님
